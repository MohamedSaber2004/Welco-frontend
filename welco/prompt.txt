1. WELCO VISUAL DIRECTION — "Surgical Precision Dashboard"
==================================================

Target feel: premium, clean, trustworthy B2B medical marketplace + enterprise console. Minimal decoration, maximum clarity. Usability over decoration. No generic AI look, no heavy gradients, no random colors, no oversized type, no excessive shadows/rounding.

Color system — USE THESE EXACT TOKENS (extend `tokens.css`, never hardcode):
* Light: primary Electric Indigo `--wl-primary #4F46E5` (hover `#4338CA`, active `#3730A3`, soft `#EEF2FF`, faint `#F5F3FF`); accent Precision Cobalt `--wl-accent #6366F1` (soft `#EEF2FF`); paper `#F8FAFC`, surface `#FFFFFF`, soft `#F1F5F9`, hover `#E2E8F0`; line `#E2E8F0`, strong `#CBD5E1`; ink-strong `#0F172A`, ink `#1E293B`, soft `#475569`, muted `#64748B`.
* Semantic (light): success `#10B981`/`#ECFDF5`, warning `#F59E0B`/`#FFFBEB`, danger `#F43F5E`/`#FFF1F2`, info `#0EA5E9`/`#F0F9FF`.
* Dark (Discord palette, already in tokens): bg `#1E1F22`, surface `#2B2D31`, card `#313338`, input `#383A40`, hover `#404249`, line `rgba(255,255,255,0.08)`; text `#F2F3F5`/`#DBDEE1`/`#B5BAC1`/muted `#949BA4`; primary blurple `#5865F2` (hover `#4752C4`, soft `rgba(88,101,242,0.16)`), accent `#949CF7`; success `#57F287`, warning `#FEE75C`, danger `#ED4245`, info `#00A8FC` (softs at 0.14 alpha).
* Status colors are FIXED: active/success=emerald, pending/warning=amber, failed/closed/danger=rose, info Cobalt/sky. Same `StatusPill` mapping everywhere. Never invent a new status color per page.
* Primary actions = Indigo solid only. Secondary = surface with border. Destructive = rose. Max 1 primary CTA per viewport/section.

Typography (use vars, fluid where defined):
* Display `var(--wl-font-display)`: display `clamp(2.75rem,5vw,3.75rem)` / H1 `clamp(2rem,3.6vw,2.5rem)` / H2 `clamp(1.5rem,2.6vw,2.05rem)` / H3 `1.28rem` / H4 `1.08rem`, tracking `-0.026em` display / `-0.012em` tight, weight 700-800 display, 600-700 H3/H4.
* Body `var(--wl-font-body)`: `0.95rem`, line-height `1.62`; small `0.84rem`; caption/mono-label `0.72rem`, uppercase, `0.05-0.08em` tracking for labels/eyebrows/rail sections.
* Numbers, IDs, order numbers, SKUs, money: `JetBrains Mono` with `tabular-nums`.
* RTL: `[dir="rtl"]` auto-switches to Alexandria/IBM Plex Sans Arabic with line-height 1.68 — do not force Latin fonts.

Shape / depth / motion:
* Radii: cards `12-16px`, inputs/buttons `10px`, pills/badges `999px`. No fully-rounded cards, no oversized radii.
* Shadows: `var(--wl-shadow-card)` for cards, `--shadow-sm/md` on hover only, `--wl-shadow-primary` for primary buttons. No heavy multi-layer shadows. Top hairline laser accent (`linear-gradient(90deg, transparent, primary, transparent)`, 1px) ONLY on interactive stat cards on hover — subtle, not everywhere.
* Motion: `var(--wl-transition) 0.18s cubic-bezier(0.16,1,0.3,1)`; hover lift max `-2px`; focus ring `var(--wl-focus-ring)` (danger variant for destructive). Respect `prefers-reduced-motion`.
* Spacing: 4px harmonic base; page `padding-top 1.75rem / bottom 3.5rem / gap 1.5rem`, card padding `1.5rem` (`1rem` sm, `2rem` lg), form gap `1.25rem`, field gap `0.45rem`, table cell `0.85rem 1.15rem`, modal `1.5rem`. Max content width `1280px` (admin shell `1560px`). Controls min-height `44px` touch target (`36px` sm, `52px` lg).

5. STATES, FORMS, FEEDBACK, RESPONSIVE, A11Y — NON-NEGOTIABLE
==================================================

* States: every async view wires Loading (SkeletonLoader/LoadingBar) + Empty (EmptyState + CTA) + Error (ErrorState + Retry) + Success (toast via `toastService` + inline confirmation). Never blank screens, never silent failures.
* NEVER fabricate data: no mock providers/products/rates/users. If an API returns nothing, show the EmptyState — never fallback sample records. Currency conversion with no rates shows original prices with the `rateUnavailable` badge.
* Forms: label above input, 44px height, border `var(--wl-line)` → focus indigo + focus ring, error rose border + message with `aria-describedby`, required `*`, disabled 45% opacity, 2-col `.form-row` only for genuinely paired fields (city/zip), single column on mobile.
* Toasts/modals/dropdowns/tabs/pagination/breadcrumbs/tooltips: reuse existing components; consistent radius/shadow/motion; toasts top-end, auto-dismiss, action link where useful.
* Responsive: verify 1440 / 1280 / 1024 / 768 / 480 / 360 + RTL. Sidebar→pills, tables→cards, forms→1col, header→hamburger (`AppMobileNav`), grids collapse, touch targets ≥44px, no horizontal overflow (`overflow-x: clip` on shell), no clipped text, no overlapping.
* A11y: contrast ≥4.5:1 body / 3:1 large, visible focus rings, keyboard-navigable nav/menus/modals/tables, semantic landmarks (header/main/nav/footer, h1 once), associated `<label>`, `aria-live` for toasts/announcer (router already announces titles — keep), logical tab order, `aria-expanded` on toggles, `role=dialog aria-modal` on modals. No a11y sacrifice for visuals.
* Performance/architecture: reuse components + CSS vars; CSS over JS animation; lazy-route (already) + `AppImage` lazy + lazy charts; no new deps without real value; split >400-line views, delete duplicated button/input/card/table CSS into shared files; keep `preflight: false` + Tailwind config mapping intact.
* Images: remote files may 404 — `AppImage` + broken-URL cache fail silently to placeholders. Never hotlink mock filenames as data.
